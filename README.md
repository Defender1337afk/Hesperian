# Hesperian

Лаунчер Minecraft для версий от 1.16.5 до новейших. Название от Гесперид, хранительниц сада с золотыми яблоками.

Интерфейс основан на дизайн-системе Sprout IDE.

## Что умеет

- **Версии.** Релизы и снапшоты от 1.16.5. Нужная Java (8, 17, 21 или 25) скачивается сама.
- **Загрузчики модов.** Fabric, Forge и NeoForge.
- **Магазин.** Моды, текстур-паки и шейдеры с Modrinth и CurseForge, обязательные зависимости ставятся сами.
- **Модпаки.** Каталог готовых сборок с Modrinth в один клик, импорт и экспорт `.mrpack`.
- **Сборки.** У каждой свои моды, миры, настройки, память и аргументы JVM. Обновления модов, текстур и шейдеров находятся по одной кнопке, даже для файлов, добавленных вручную.
- **Статистика.** Графики FPS и памяти за каждую сессию, история запусков, игровое время по дням и подсказки, если Java не хватает памяти.
- **Конфликты модов и разбор вылетов.** Дубли, моды не под тот загрузчик или версию и недостающие зависимости видны до запуска. Если игра упала, лаунчер объяснит причину по-человечески.
- **Скины.** 3D-превью, библиотека и встроенный браузер сайтов со скинами. С лицензией меняются скин и плащ.
- **Аккаунты.** Microsoft и офлайн-профили. Токены шифруются средствами системы.
- **Для слабых ПК.** Окно выгружается на время игры, память для Java подбирается сама, «Ускорить сборку» ставит Sodium, Lithium, FerriteCore и другие моды.
- **Интерфейс.** Legacy и New, тёмное, светлое, чёрное или системное оформление, акцент любого цвета, фон из картинки, GIF или видео, перетаскивание файлов в окно.
- **Удобство.** Трей с последними сборками, ярлыки сборок на рабочий стол, бэкап миров перед запуском, напоминание о перерыве, режим стримера, горячие клавиши на F1.
- **Автообновление.** Лаунчер сам скачивает новую версию, проверяет её и перезапускается.
- **Свой установщик.** Права администратора не нужны, исходники в `installer/`. Ключи: `--silent`, `--dir <папка>`, `--no-desktop`, `--no-start-menu`; удаление `--uninstall [--purge]`.

## Запуск

```
npm install
npm run dev        # разработка
npm run dist       # установщик release/Hesperian-Setup-<версия>.exe
npm run dist:linux # release/Hesperian-<версия>-x86_64.AppImage и .tar.gz
```

AppImage на Linux требует пакет `fuse2`. Без него распакуйте `.tar.gz` и запускайте файл `hesperian`.

## Вход через Microsoft

В готовых сборках вход работает сразу. При сборке из исходников нужен свой Client ID из [portal.azure.com](https://portal.azure.com) (App registrations, Personal Microsoft accounts only, Allow public client flows) с одобренным доступом к Minecraft API: [aka.ms/mce-reviewappid](https://aka.ms/mce-reviewappid). Его вставляют в **Настройки → Аккаунт**.

## Где лежат данные

Windows: `%APPDATA%\Hesperian`, Linux: `~/.config/Hesperian`. Настройки и аккаунты в корне, версии и сборки в `game\`. Папку данных можно сменить в настройках.

## Безопасность

В версиях 1.16.5–1.18.0 есть уязвимость Log4Shell. Hesperian при каждом запуске подключает исправленный конфиг логирования от Mojang и флаг `log4j2.formatMsgNoLookups`.
