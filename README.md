# Hesperian

Лаунчер Minecraft для версий от 1.16.5 до новейших. Название от Гесперид, хранительниц сада с золотыми яблоками.

Интерфейс основан на дизайн-системе Sprout IDE.

## Что умеет

- **Версии.** Релизы и снапшоты от 1.16.5. Нужная Java (8, 17, 21 или 25) скачивается автоматически.
- **Загрузчики модов.** Fabric, Forge и NeoForge.
- **Модпаки.** Каталог готовых сборок с Modrinth: один клик, и сборка создана со всеми модами, загрузчиком и настройками. Импорт и экспорт файлов `.mrpack`.
- **Магазин.** Моды, текстур-паки и шейдеры с Modrinth, обязательные зависимости ставятся сами. Наш мод Astra Visuals лежит внутри лаунчера и находится поиском по слову `defender` (`npm run dist` берёт свежие файлы из соседней папки `AstraVisuals`).
- **Сборки.** У каждой свои моды, миры, настройки, память и аргументы JVM. Обновления модов, текстур и шейдеров находятся по одной кнопке, даже для файлов, добавленных вручную.
- **Аккаунты.** Лицензия через Microsoft и офлайн-профили. Токены шифруются средствами системы.
- **Кастомизация.** 4 обычных темы, акцент любого оттенка, плотность, скругления, размер интерфейса, фон, свой CSS.
- **Тема «Кристалл».** Меняет весь интерфейс: стекло, плитки и страницы вместо панелей и вкладок.
- **Свой установщик.** Рисуется вручную в стиле «Рощи», основной темы лаунчера, права администратора не нужны, в `installer/`. Ключи: `--silent`, `--dir <папка>`, `--no-desktop`, `--no-start-menu`; для удаления `--uninstall [--purge]`.
- **Удобство.** Палитра команд, горячие клавиши, панель вывода игры с фильтром.


## 1.2 Cursed: что нового

- **Режим для слабых ПК** в настройках: окно лаунчера выгружается на время игры, Java получает память по объёму ОЗУ и лёгкие флаги G1, анимации выключаются.
- **Ускорить сборку** на странице сборки: Sodium, Lithium, FerriteCore, ImmediatelyFast, EntityCulling и ModernFix под загрузчик и версию.
- **Готовые плагины** (`resources/plugins`): статистика игры, напоминание о перерыве, бэкап миров. API плагинов умеет `worlds.list` и `worlds.backup`.
- **Серверы**: свой сервер Vanilla или Fabric в один клик (EULA, server.properties, Java ставятся сами), адреса для друзей с пометкой Radmin VPN, Hamachi и локальной сети, консоль с командами, игроки онлайн. Серверы друзей добавляются по IP, у каждого живой пинг, а «Играть» сразу подключает игру к серверу.
- Сборка: `npm run dist` (установщик Windows), `npm run dist:portable` (один exe), `npm run dist:linux`.

## Запуск

```
npm install
npm run dev        # разработка
npm run dist       # установщик release/Hesperian-Setup-<версия>.exe
npm run dist:linux # release/Hesperian-<версия>-x86_64.AppImage и .tar.gz
```

AppImage на Linux требует пакет `fuse2`. Без него распакуйте `.tar.gz` и запускайте файл `hesperian`.

## Вход через Microsoft

Лаунчеру нужен свой Client ID, общий ключ для всех приложений Microsoft не выдаёт.

1. На [portal.azure.com](https://portal.azure.com) откройте **App registrations**, затем **New registration**.
2. В **Supported account types** выберите **Personal Microsoft accounts only**.
3. В разделе **Authentication** включите **Allow public client flows**.
4. Скопируйте **Application (client) ID** в Hesperian: **Настройки**, раздел **Аккаунт**.
5. Подайте заявку на доступ к Minecraft API: [aka.ms/mce-reviewappid](https://aka.ms/mce-reviewappid).

Пока Mojang не одобрит заявку, вход будет останавливаться на шаге «Вход в Minecraft» с понятной ошибкой.

## Где лежат данные

Windows: `%APPDATA%\Hesperian`, Linux: `~/.config/Hesperian`. Настройки и аккаунты в корне, версии и сборки в `game\`. Папку данных можно сменить в настройках.

## Безопасность

В версиях 1.16.5–1.18.0 есть уязвимость Log4Shell. Hesperian при каждом запуске подключает исправленный конфиг логирования от Mojang и флаг `log4j2.formatMsgNoLookups`.
